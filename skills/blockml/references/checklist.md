# 交付前自检

## 必过

- [ ] `npx blockml validate <file>` → **0 error**
- [ ] 每个 warning 都看过：未知 kind 是否该换成内置值？未知属性是否拼错？
- [ ] `npx blockml render <file>` → 生成 HTML，文件大小合理（一般 40–120 KB）
- [ ] 用浏览器打开 HTML：能渲染、能缩放、能拖动、无控制台报错

## 内容

- [ ] 节点数 6–16；超过就拆图
- [ ] 每个节点的 `tech` 一行内说得清它是什么
- [ ] 每条边都写了「靠什么连」（路径、协议、端口）
- [ ] 外部依赖至少有一条 `opt` 或 `gate` 表达强弱
- [ ] 没有「正确但没用」的节点（比如为了凑数加的背景系统）

## 事实

- [ ] 涉及具体数值（连接池、条数限制、超时）的断言都能指到出处
- [ ] `src` 用的是真实路径（`docs/...`、`Xxx.java:120`），不是猜测
- [ ] 没有把「计划中」写成「已上线」

## 视觉

- [ ] 两个组框不重叠
- [ ] 没有标签压在节点上
- [ ] 长斜线不超过 3 条；超过说明布局该重排
- [ ] 图例只显示实际出现的 kind

## 收尾

- [ ] `.blockml` 文件和渲染出的 HTML 一起交付
- [ ] 告诉用户：拖完节点后点「下载源码」可以拿回带坐标的版本
